FPS Lab Android — proyecto fuente

IMPORTANTE:
- Es un panel flotante de demostración.
- Los interruptores Aimbot/Wallhack son controles visuales sin efecto sobre juegos.
- No lee memoria, no inspecciona pantalla, no toca archivos del juego y no altera Counter Flame.
- La superposición requiere que el usuario habilite manualmente "Mostrar sobre otras apps".

Cómo generar el APK:
1. Descomprimí el ZIP en una computadora con Android Studio.
2. Abrí la carpeta FPSLabAndroid.
3. Esperá a que Gradle sincronice el proyecto.
4. Elegí Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio generará el APK en app/build/outputs/apk/debug/.

Este entorno no tiene Android SDK/Gradle instalado, por eso entrego el proyecto fuente y no un APK compilado.
